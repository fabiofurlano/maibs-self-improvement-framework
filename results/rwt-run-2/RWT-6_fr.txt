# Python Function to Get GitHub Repository Information

Here's a complete Python function that fetches repository information from the GitHub API v3:

```python
import requests

def get_repo_info(owner: str, repo: str) -> dict:
    """
    Fetches repository information from GitHub API.
    
    Args:
        owner: Repository owner (username or organization)
        repo: Repository name
        
    Returns:
        Dictionary containing repository information with keys:
        - name: Repository name
        - stars: Number of stargazers (stargazers_count)
        - language: Primary programming language
        - open_issues: Count of open issues
        
    Raises:
        requests.exceptions.HTTPError: If the request fails (except rate limiting)
    """
    # GitHub API endpoint for repository information
    url = f"https://api.github.com/repos/{owner}/{repo}"
    
    # Required headers for GitHub API v3
    headers = {
        "Accept": "application/vnd.github+json",
        "X-GitHub-Api-Version": "2022-11-28"
    }
    
    try:
        response = requests.get(url, headers=headers)
        
        # Check for rate limiting (403 status)
        if response.status_code == 403 and \
           'X-RateLimit-Remaining' in response.headers and \
           int(response.headers['X-RateLimit-Remaining']) == 0:
            reset_time = int(response.headers.get('X-RateLimit-Reset', 0))
            wait_time = max(reset_time - int(time.time()), 0)
            raise requests.exceptions.HTTPError(
                f"Rate limit exceeded. Please wait {wait_time} seconds before trying again."
            )
        
        # Raise for other HTTP errors
        response.raise_for_status()
        
        data = response.json()
        
        return {
            "name": data.get("name", ""),
            "stars": data.get("stargazers_count", 0),
            "language": data.get("language", ""),
            "open_issues": data.get("open_issues_count", 0)
        }
        
    except requests.exceptions.RequestException as e:
        raise requests.exceptions.HTTPError(f"Failed to fetch repository info: {str(e)}")
```

2. **Proper Headers**:

3. **Rate Limiting Handling**:

   - Provides a helpful error message with wait time

4. **Result Format**:
   - Returns a dictionary with the requested fields
