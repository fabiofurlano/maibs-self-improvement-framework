# Python List Comprehensions

Python list comprehensions provide a concise and readable way to create lists. They are often used as an alternative to `for` loops when generating new lists by applying an expression to each item in an iterable. 

For more details on iterables, see [[Python Iterables]]. To compare with other looping constructs, visit [[Python Loops]].

## Basic Syntax

The general structure of a list comprehension is:
```python
[expression for item in iterable]
```

### Example 1: Simple List Comprehension
Create a list of squares from 0 to 9:
```python
squares = [x**2 for x in range(10)]
print(squares)  # Output: [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
```

### Example 2: List Comprehension with Condition
Filter even numbers and square them:
```python
even_squares = [x**2 for x in range(10) if x % 2 == 0]
print(even_squares)  # Output: [0, 4, 16, 36, 64]
```

### Example 3: Nested List Comprehension
Flatten a 2D matrix into a 1D list:
```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flattened = [num for row in matrix for num in row]
print(flattened)  # Output: [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

## Advantages
- More concise and readable than traditional loops.
- Often faster due to Python's internal optimizations.

## Limitations
- Can become less readable if overused for complex logic.
- Not suitable for side effects (use a `for` loop instead).

For advanced use cases, consider [[Python Generators]].
