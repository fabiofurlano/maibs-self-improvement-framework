Here is the Python function that returns the middle third of a list, handling edge cases as specified:

```python
def get_middle_third(items: list) -> list:
    if not items:
        return []
    
    n = len(items)
    start = n // 3
    end = 2 * n // 3
    return items[start:end + 1]
```

### Explanation:
- **Edge Case Handling**: If the input list is empty, the function immediately returns an empty list.
- **Normal Case**:
  - `n` is the length of the list.
  - `start` is calculated as `n // 3`, which gives the starting index of the middle third.
  - `end` is calculated as `2 * n // 3`, which gives the ending index of the middle third.
  - The function returns the slice `items[start:end + 1]` to include the element at the `end` index (inclusive).

### Example Usage:
```python
print(get_middle_third([1, 2, 3, 4, 5, 6]))  # Output: [3, 4]
print(get_middle_third([1, 2, 3, 4, 5]))     # Output: [2, 3]
print(get_middle_third([]))                  # Output: []
```
