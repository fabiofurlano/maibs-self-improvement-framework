🖥 Local Model — Gemma 4 E4B

Minimum RAM8 GB ✓ (this machine: 32 GB)
GPUOptional (CPU-only works)
Model filegemma-4-E4B-it-Q4_K_M.gguf (4.2 GB)
Expected speed7–11 tok/s (CPU), 18+ tok/s (Vulkan GPU)
Speedup techniques

• Vulkan backend — rebuild llama.cpp with -DGGML_VULKAN=ON for 2–3× speedup on Iris Xe
• Multi-Token Prediction — llama.cpp added MTP for Gemma 4 in May 2026, ~42% speedup on larger models
• Q4_K_M quantization — already using the optimal quant for this hardware (balanced speed/quality)
